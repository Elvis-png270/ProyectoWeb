# ReVive — Antes de reemplazar, repara

Plataforma web que conecta a personas que necesitan reparar productos dañados
con reparadores y técnicos de su comunidad, para fomentar la economía circular
y reducir residuos.

## Descripción

Cuando un producto deja de funcionar, muchas personas no saben dónde repararlo,
cuánto debería costar el servicio o en qué técnico confiar. ReVive resuelve eso:
el usuario publica una solicitud de reparación (categoría, descripción,
ubicación y fotos) y la plataforma le muestra reparadores cercanos con perfil,
especialidades, calificaciones y reseñas de otros clientes.
